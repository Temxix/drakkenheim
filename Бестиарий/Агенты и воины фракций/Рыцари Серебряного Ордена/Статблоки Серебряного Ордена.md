# Статблоки Серебряного Ордена (Silver Order Statblocks)

[[Серебряный Орден|Рыцари Серебряного Ордена]] сражаются сомкнутым строем под защитой ауры *Оплота веры*. Отдельные статблоки воинов и священнослужителей Ордена представлены в индивидуальных заметках:

- [[Солдат Серебряного Ордена]] *(Silver Order Soldier)* — ПО 1/2
- [[Послушник Серебряного Ордена]] *(Silver Order Acolyte)* — ПО 1
- [[Ветеран Серебряного Ордена]] *(Silver Order Veteran)* — ПО 3
- [[Капеллан Серебряного Ордена]] *(Silver Order Chaplain)* — ПО 4
- [[Кавалерист Серебряного Ордена]] *(Silver Order Cavalier)* — ПО 5
- [[Огнекопейщик Серебряного Ордена]] *(Silver Order Flamelancer)* — ПО 6
- [[Рыцарь-капитан Теодор Маршал (Расширение)]] *(Theodore Marshal, Standalone CR 15)*
