# Алмаз с горы Кадат

## Описание

Алмаз с горы Кадат — редчайший драгоценный камень, используемый как материальный компонент для могущественных заклинаний. Упоминается в контексте [[Замок Драккен|Замка Драккен]] как один из ценнейших артефактов.

## Свойства

- Материальный компонент для заклинаний высшего уровня (Истинное воскрешение и др.)
- Исключительная ценность и редкость
- Может быть найден в сокровищницах [[Замок Драккен|Замка Драккен]]
