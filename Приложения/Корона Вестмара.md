# Корона Вестмара

## Описание

Корона Вестмара — легендарный артефакт, символ власти королей [[Вестмар|Вестмара]]. Корона находится в [[Замок Драккен|Замке Драккен]] и является одной из целей финала кампании.

## Значение

- Символ легитимной власти над [[Вестмар|Вестмаром]]
- Ключевой предмет для личного квеста «Заявить Права на Трон»
- [[Фонари]] стремятся вернуть Корону для восстановления монархии
- Находится в глубинах [[Замок Драккен|Замка Драккен]]

## Связанные заметки

- [[Замок Драккен]] — место нахождения Короны
- [[Крах Дома фон Кессель]] — история падения королевской линии
- [[Вестмар]] — королевство
