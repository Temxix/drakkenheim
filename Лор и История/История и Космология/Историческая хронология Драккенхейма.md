# Историческая хронология Драккенхейма (Historical Timeline)

> Назад к обзору Приложения Г: [[Приложение Г. Мир Драккенхейма]] | См. также: [[Магия и Религии Драккенхейма]]

![[Кремнёвый пистоль и пороховница (Flintlock Pistol and Powder Flask).png]]

| Год | Событие |
| :--- | :--- |
| **Год −12** | Золотая комета приводит Тарну к архангелам Габриэлле и Михаилу, и она становится Первым Паладином. |
| **Год 1** | Мученичество святой Тарны, спасшей мир от безумия короля-колдуна Ксандора XIII. После её гибели последователи распространяют знание о том, как направлять [[Вера Священного Пламени]], и развязывают войну против королей-колдунов. |
| **Около 300** | Владычество королей-колдунов наконец рушится. Всё больше людей учится владеть светом Священного Пламени; верные жрецы закладывают основы ранней церкви. |
| **Год 381** | Поклявшись, что тираны-маги никогда больше не будут править, новоизбранная Божественный Матриарх Священного Пламени одобряет преследование тайных заклинателей. |
| **Около 500** | После столетия гонений группа уцелевших магов основывает [[Аметистовая Академия]] как тайное общество для собственной защиты. |
| **Около 600** | Дом фон Драккен основывает малое королевство вдоль реки Дранн и закладывает фундамент [[Замок Драккен (Обзор)]]. |
| **Год 678** | [[Серебряный Орден]] получает священное посвящение для охоты на Аметистовую Академию. |
| **Около 700** | Между дворянскими домами, поддерживаемыми Аметистовой Академией, и домами, поддерживаемыми Верой Священного Пламени, вспыхивают кровопролитные войны. |
| **Год 743** | [[Эдикты Люмена]] кладут конец войнам, устанавливая чёткое разделение полномочий между магами, духовенством и знатью. |
| **Около 800** | Дом фон Драккен угасает, вызывая 150 лет кризисов престолонаследия. |
| **Год 965** | [[Крах Дома фон Кессель]] — Дом фон Кессель занимает престол Драккенхейма и учреждает Королевство [[Вестмар (Обзор и история)]]. |
| **Около 1000** | Монархия [[Элирия (Обзор и история)]] рушится; Божественный Матриарх начинает назначать лорда-регента. |
| **Год 1015** | [[Космологическая Часовая Башня]] Драккенхейма загадочным образом останавливается. |
| **Год 1093** | [[Лукреция Матиас]] пишет эссе, предсказывающее скорое возвращение кометы Тарны и гласящее, что её явление на земле возвестит зарю новой эры для верных Божественному Свету. Её апокалиптические пророчества крайне непопулярны у официального духовенства, и её труды подавляются. |
| **Год 1111** | Метеорит поражает Драккенхейм 16 сентября в 20:13. |
| **Год 1112** | Неудачная попытка отвоевать Драккенхейм оборачивается гибелью тысяч солдат в Дымке. Немногие вернувшиеся поражены безумием. |
| **Год 1113** | Лукреция Матиас значительно расширяет свой первоначальный труд и публикует «Завет Падающего Огня». Точность её давнего предсказания приносит ей множество последователей, и она планирует личное паломничество в Драккенхейм. |
| **Год 1114** | После ещё двух катастрофических военных экспедиций по возвращению Драккенхейма кризис престолонаследия между уцелевшими представителями Дома фон Кессель перерастает в гражданскую войну Вестмара. |
| **Год 1115** | Пока бушует гражданская война, несколько отрядов авантюристов проникают в руины Драккенхейма за добычей. К всеобщему изумлению, некоторые возвращаются живыми. Они рассказывают о жутких чудовищах внутри и приносят странные образцы опасного кристалла. |
| **Год 1116** | Лукреция Матиас совершает паломничество в Драккенхейм и лично достигает Края [[Кратер]]. Она возвращается в Элирию, чтобы проповедовать своё учение. |
| **Год 1117** | Аметистовая Академия начинает нанимать искателей приключений для сбора «осколков метеорита» ради исследований. Странные кристаллы получают название делериум. |
| **Год 1119** | Манфред фон Кессель убит. Цецилия фон Кессель умирает при загадочных обстоятельствах. Гражданская война затухает без явного наследника. |
| **Год 1120** | Лукреция Матиас объявлена еретичкой и отлучена от церкви Священного Пламени Божественным Матриархом. Она возвращается в Драккенхейм. |
| **Год 1121** | Всё больше искателей приключений устремляется в руины Драккенхейма. [[Деревня Эмбервуд (Обзор)]] становится перевалочным центром для охотников за сокровищами и головорезов. |
| **Год 1122** | Вера Падающего Огня стремительно ширится, и всё больше паломников отправляется в опасный путь к Драккенхейму. Удача улыбается немногим. |
| **Год 1123** | Сформирован 4-й Временный Экспедиционный Отряд по Возвращению Столицы — [[Фонари]]. Они начинают свои первые вылазки в Драккенхейм. |
| **Год 1124** | Фонари наконец закрепляются у старых Врат Пастуха, а затем в [[Гарнизон Драккенхейма]], но не могут продвинуться дальше вглубь города. |
| **Год 1125** | Небольшой отряд [[Последователи Падающего Огня]] занимает опорный пункт в [[Монастырь Святой Селины]], чтобы помогать будущим паломникам на пути к Кратеру. |
| **Год 1126** | 4 марта — начинаются события кампании «Подземелья Драккенхейма». |
