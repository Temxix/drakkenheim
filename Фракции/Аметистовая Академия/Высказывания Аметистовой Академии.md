# Высказывания Аметистовой Академии (Sayings of the Amethyst Academy)

![[Знамя Аметистовой Академии над руинами (акварель) (Amethyst Academy Banner Watercolor).jpeg]]

Одна из самых сложных задач при ведении фракции — придумывать уместные реплики для её представителей. Импровизировать такие фразы прямо за столом бывает непросто. Эта таблица содержит подборку цитат, которые помогут вам в проведении социальных столкновений с [[Аметистовая Академия|Аметистовой Академией]].
