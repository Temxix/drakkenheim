# Магические предметы (Appendix E: Magic Items)

В этом приложении представлен перечень новых магических предметов из мира [[Обзор города|Драккенхейма]]. Помимо описания и свойств каждого магического предмета, каждая статья включает требования к созданию и рецепт изготовления этого предмета.

Приложение завершается [[Рецепты SRD|рецептами для подборки магических предметов из SRD]].
