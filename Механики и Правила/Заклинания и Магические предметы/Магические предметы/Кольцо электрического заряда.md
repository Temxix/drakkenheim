# Кольцо электрического заряда (Electric Charge Ring)

*Кольцо, редкое*

![[Кольцо электрического заряда (Electric Charge Ring).png]]

Это кольцо, состоящее из живой молнии, выковано из элементальной пыли, спрессованной в самоцвет вокруг линзы глаза конструкта, омытой в кислотных железах монстра, прежде чем быть оправленной в анимус элементаля.

Когда вы творите заклинание, используя ячейку заклинаний, наносящее урон электричеством, выберите одну цель, провалившую свой первый спасбросок против этого заклинания. Это существо получает состояние [[Новые состояния|Шокированный]] до начала вашего следующего хода.

## Создание (Crafting)

Для создания *кольца электрического заряда* требуются Редкая [[Шаг 3 — Поиск мастерской|мастерская]] и следующие Редкие компоненты:

- **[Анимус]** Анимус Элементаля
- **[Пыль]** Элементальная пыль
- **[Органы]** Глаз Конструкта
- **[Органы]** Железы
