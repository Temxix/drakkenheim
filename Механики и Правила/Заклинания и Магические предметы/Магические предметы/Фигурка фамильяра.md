# Фигурка фамильяра (Familiar Figurine)

*Чудесный предмет, необычный*

![[Фигурка фамильяра (Familiar Figurine).png]]

Один раз в день действием Магия (*Magic*) вы можете использовать эту тонко вырезанную фигурку, чтобы сотворить заклинание *поиск фамильяра*.

## Создание (Crafting)

Для создания *фигурки фамильяра* требуются Необычная [[Шаг 3 — Поиск мастерской|мастерская]] и следующие Необычные компоненты:

- **[Анимус]** Любой
- **[Кости]** Кости Великана
- **[Пыль]** Пыль Элементаля или Феи
