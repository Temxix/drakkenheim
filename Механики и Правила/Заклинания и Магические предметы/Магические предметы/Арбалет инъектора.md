# Арбалет инъектора (Injector’s Crossbow)

*Оружие (любой арбалет), редкое (требуется настройка)*

Этот арбалет покрыт металлическими пластинами, изысканными декоративными заострёнными наконечниками вдоль дубового ложа и цевья. Ствол и плечи усилены стальными пластинами конструкта, а рукоять обтянута пропитанной кожей из шкуры монстра. Тетива сплетена из волос, а кожаные крепления удерживают на месте ряд шприцев. Из приклада арбалета выходит система разнообразных трубок, соединённых с алхимической камерой на боку оружия. Механическое колесо подаёт дротики на место после их заполнения, автоматически перезаряжая арбалет для лёгкой стрельбы.

Вы получаете бонус +1 к броскам атаки и урона, совершаемым этим магическим арбалетом. Этот арбалет игнорирует свойство *Перезарядка*, и вам не нужна свободная рука, чтобы зарядить в него боеприпас.

Раз в ход, когда вы попадаете по существу дальнобойной атакой из этого арбалета, вы можете применить один из следующих ядов:

- **Смертоносный (Virulent).** Цель получает дополнительно 2к6 урона ядом.
- **Ослабляющий (Weakening).** Цель должна совершить спасбросок Телосложения СЛ 15. При провале она получает состояние [[Новые состояния#Ослабленный (Weakened)|Ослабленный]] до начала вашего следующего хода.
- **Обездвиживающий (Immobilizing).** Цель должна совершить спасбросок Силы СЛ 15. При провале она получает состояние [[Новые состояния#Обездвиженный (Immobilized)|Обездвиженный]] до начала вашего следующего хода.

## Создание (Crafting)

Для создания *арбалета инъектора* требуются Редкая [[Шаг 3 — Поиск мастерской|мастерская]] и следующие Редкие компоненты:

- **[Анимус]** Любой анимус
- **[Жидкость]** Химический раствор
- **[Волосы]** Волосы
- **[Шкура]** Пластины
- **[Шкура]** Кожа
- **[Природное оружие]** Иглы Инъектора
