# Случайные Столкновения

## Механика

В [[Драккенхейм|Драккенхейме]] повсюду таятся опасные монстры. При перемещении по руинам каждый игрок бросает **1к20**:
- За каждый час исследования города
- Когда игроки нерешительны в опасной обстановке
- Когда нужно внести разнообразие
- Когда это предписано обстоятельствами приключения

**Столкновение происходит**, если любой игрок бросит **естественную 1**.

**Естественная 20** приносит удачу: застать врагов врасплох, месторождение [[Делериум|делериума]], монстры с сокровищами, союзники поблизости.

**Все единицы**: Худшее, что может случиться — происходит!

> Размер кубика можно уменьшить до 1к10 или 1к6 для повышения опасности.

## Описания столкновений

| Столкновение                    | Описание                                                             |
| ------------------------------- | -------------------------------------------------------------------- |
| **Академический Исследователь** | Маг [[Аметистовая Академия]] и 1к4 мага ограждения                   |
| **Злая Мебель**                 | 1к4 мимиков под видом мебели                                         |
| **Гнездо Химеры**               | Химера на высоком шпиле                                              |
| **Уборочный Куб**               | Студенистый куб в канализации                                        |
| **Багровая Графиня**            | Багровая Графиня и 2к4 гарпий                                        |
| **Дремлющий Громила**           | Дымчатый громила с осколком делериума                                |
| **Глубинные**                   | 3к6 водных делериумных отбросов и 1 чууль                            |
| **Двойные Проблемы**            | Два столкновения сразу, сражающиеся друг с другом                    |
| **Утопленные Мертвецы**         | 3к6 дымчатых оболочек в затопленном туннеле                          |
| **Призыв Палача**               | Персонажи попадают на [[Площадь Резни]]                              |
| **Павшие Герои**                | 2к4 дымчатых умертвий — бывшие приключенцы                           |
| **Охотники Гармиры**            | 3к6 гармиров и 1к4 воргов                                            |
| **Гармиры-разрушители**         | 2к6 берсерков-гармиров с 1к4 адскими гончими                         |
| **Призрачные Огни**             | 1к4 блуждающих огней (2к6 во Внутреннем Городе)                      |
| **Говорящая Плоть**             | 1к4 бормочущих ротовиков (протеанская мерзость во Внутреннем Городе) |
| **Сумеречный Луч**              | Плащевик охотится с крыш                                             |
| **Замкнутый Круг**              | Персонажи теряются на 1к4 часов                                      |
| **Стая гарпий**                 | 3к6 гарпий                                                           |
