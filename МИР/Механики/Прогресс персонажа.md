# Прогресс персонажа

Материалы кампании представляют вызов для персонажей с 1 по 13 уровни. Кампания спроектирована как нелинейная, и прогресс персонажей отражает их достижения в исследовании [[Драккенхейм]]а и взаимодействии с фракциями.

| Уровень | Ожидаемый прогресс в кампании |
|---------|------------------------------|
| **1-й** | [[Дорога в Драккенхейм]] (начало приключения). |
| **2-й** | Знакомство с [[Деревня Эмбервуд|деревней Эмбервуд]] и Внешним городом. |
| **3-й** | Первые контакты с фракциями, выполнение их начальных заданий. |
| **4-й** | Исследование окраинных локаций, получение репутации у фракций. |
| **5-й** | Проникновение во Внутренний город через Городские Стены. |
| **6-й** | Исследование внутренних районов города, столкновение с серьезными угрозами. |
| **7-й** | Пиршества в [[Собор Святого Витрувио|соборе Святого Витрувия]], Совет в соборе. |
| **8-й** | Экспедиция в [[Кратер]] и взаимодействие с основными тайнами [[Делериум]]а. |
| **9-й** | Штурм оплотов фракций. |
| **10-й** | Получение Печатей Драккенхейма. |
| **11-й** | Убийство лидера враждебной фракции. |
| **12-й** | Экспедиция в [[Замок Драккен]]. |
| **13-й** | Решение судьбы Драккенхейма и кульминация [[Личные Квесты|личных квестов]]. |

> Мой лучший совет, как остаться в живых в Драккенхейме — это просто убивать всё, что движется. Нет времени задавать вопросы. Колебания опасны.
> — Себастьян Кроу.
